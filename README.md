**Problem:**
This application is primarily intended for accounting students and future CPA’s. However, it can be used by anyone trying to learn accounting. The application addresses a variety of problems. First, it addresses the problem of there being a finite number of practice problems in textbooks; being able to generate an infinite amount of problems can help students to continue studying effectively rather than redoing problems they already have done and already know the answer to. Second, it addresses a problem for CPA candidates who want additional practice working with IFRS standards but may have limited access to new cases. Lastly, for people who want to learn accounting but don’t want to purchase a textbook, this can be a great resource to learn some basic accounting.

**Core function:**
The application provides users with access to practice problems that range from beginner to advanced journal entries; comprehensive journal entry scenario problems that tie into financial statements; and application of IFRS, which is useful for upper-level accounting students and CPA candidates. The theory tab also lets users learn more about specific account types, access short general readings, and practice theory through multiple-choice questions. Lastly, the “Ask AI Tutor” feature lets students access answers to frequently asked questions. This will help students get detailed answers to questions they may have.

**Testing:**
We tested the application through a variety of different inputs. For normal inputs, we generated multiple-choice questions, practice questions and cases and entered the expected correct answer. We then verified if the application generated appropriate questions, correct solutions, and provided correct feedback. For each normal input, the application worked appropriately. For invalid inputs, we purposefully entered the wrong answer to questions and then verified if the application marked it as incorrect and reviewed the feedback the application provided to ensure it was accurate. For each invalid input, the application worked appropriately. We also tested what happens if the page is refreshed, ensuring that user progress is saved locally. Additionally, we added the ability for users to reset their locally saved progress if they wish through the “Review & Progress” tab. Finally, we tested the application on a phone-sized display and found that all features work appropriately.

**Improvement:**
Throughout the development of our application, we have made several significant improvements after testing the application. Initially, the application struggled with basic arithmetic, for example, miscalculating straight-line depreciation. Thus, we constructed a prompt to have the AI revise the application's mathematics. The application also initially used US GAAP terminology, such as stockholders’ equity. A prompt was created to update the application to be Canadian-based, only using terms relevant to either IFRS or ASPE. Furthermore, the initial build didn’t provide much in the way of feedback for incorrect journal entries. We prompted the AI to tailor the application's feedback/hints specifically to the errors that the user was making in relation to the journal entries. After three incorrect attempts, the application then provides the correct answer and additional feedback on why that is the correct answer.

Once these initial improvements were made, we began focusing on improving more complicated issues. First, we looked at improving the “Ask AI Tutor” feature, which can be used to provide users with answers to common questions. In the initial build, this feature provided the same default response to every question. After some prompting, we were able to update it so that the number of frequently asked questions was increased and each answer to a question had a tailored response in a consistent, well-formatted structure. 

Next, we got some feedback from peers who thought it would be useful to make the application a broader accounting practice tool, which could be used for upper-level courses. Thus, we added increased difficulty levels for the journal entry practice and added an IFRS Application feature. This new feature is for upper-level accounting students and CPA candidates looking to practice case writing. The initial creation of this feature only provided three cases and only allowed the user to identify the relevant issues and IFRS standards. After testing, we decided that we wanted this to be more comprehensive; thus, we made it so cases could be infinitely generated and structured the response text boxes to follow the IGARU format.

Furthermore, after some feedback, we determined that there is a gap between the intro to accounting journal entries and the IFRS application tab. To have this application be used as an Accounting Practice Hub, we needed to fill this gap in difficulty. To do this, we decided to adjust the difficulty levels for the journal entry practice and multiple-choice questions. We added beginner, intro accounting, intermediate 1, and intermediate 2 difficulty levels. Each difficulty is focused on that course's related content, except for the beginner difficulty, which is an easier subset of the intro accounting questions. This helps bridge the gap between journal entry practice and IFRS application, allowing for the application to be useful for all accounting students. 

Additionally, after the application was published through Vercel, we sent the link to a peer who used the website on their phone. We had them think out loud and watched them use the application; the key issue they found related to understandability. They suggested that we look at adding a short description for each tab to make the application easier to use for first-time users. We added this, pushed changes to GitHub, and updated the public site on Vercel.

**Limitations:**
Before real-world use, the application would likely need further validation relating to the IFRS Application feature and complex journal entries. This is because the content is AI-generated, which means there may sometimes be slight inaccuracies, especially surrounding areas that require professional judgement. Additionally, since the cases and journal entries can be continuously generated, it is hard to guarantee that the application will always be mistake-free, despite us running multiple tests to ensure there are no mistakes. If this application were to be used as a real-world practice tool, it would be important to bring in a group of CPA’s to work through numerous problems and identify any mistakes, especially surrounding areas of professional judgement.

Furthermore, one thing that this application does not do, is it does not automatically update. IFRS and ASPE standards are continuously updated on an ongoing basis, and our application is based on the most recent versions of these standards. However, if new standards are added, the application does not auto-update its understanding. To ensure the application updates with new standards, the underlying instructions would need to be manually updated.

**AI use and contributions:**
We used Google AI Studio to develop our application. However, the project idea, main features, and bug fixes were all based on decisions that we made as a group. To make adjustments to the application in Google AI Studio, we used the detailed prompt structures from Mission 4 on the lab website, replacing content in the brackets with appropriate adjustments for our application. 

As a group, we identified a common issue that we had in previous accounting courses and, following this, prompted the AI to make a website that would fix this issue. In this case, it was the issue of not having enough exposure to a variety of practice problems. We then had to decide who the application would be intended for; we determined that it should be a practice hub that would be useful for a variety of accounting courses. We prompted the AI, using specific course content, to provide course-related difficulties and features. 

Our group also verified that the application was working as intended. To do this, we used the application's features and checked the accuracy of the solutions using notes from past courses and our accounting knowledge. We also tested the application's response to correct and incorrect answers to ensure that the feedback feature was working correctly. After we completed the verification process, we took note of each identified issue and created prompts to address these issues. This allowed us to finalize the application and have it work as we intended.
